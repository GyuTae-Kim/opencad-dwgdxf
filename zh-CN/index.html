OpenCAD 免费 DWG·DXF CAD

它是一款免费的 2D Web CAD，允许您打开或创建新的 DWG/DXF 绘图、绘制、编辑和保存它们。无需安装或注册会员，可直接在浏览器中使用，绘图文件在本机上处理，无需发送到服务器。

最近文档

此处显示的是在此浏览器中打开的图形。

支持的格式和功能

  • 打开DWG R13~R2018、DXF R12~R2018（ASCII/二进制），创建新图纸
  • 绘制直线、多段线、圆和圆弧；进行移动、复制、修剪和倒角等修改；编辑控制点
  • 编辑尺寸、引线、文本、图案填充、表格、块、图层和布局
  • 保存DWG R2000~R2018、DXF R12~R2018，测量距离/角度/面积
  • 输出为 PDF、PNG、SVG

程序准备就绪后，即可立即使用“新建绘图”、拖放文件或点击“打开文件”开始绘图。您还可以通过“打开示例绘图”来探索各项功能。需要使用支持 JavaScript 和 WebGL2 的浏览器，例如最新版本的 Chrome、Edge、Firefox 或 Safari。

免费CAD检查和修改DWG·DXF图纸

当您需要检查和更正收到的图纸，或绘制新图纸并将其保存为 DWG 或 DXF 格式时，可以直接在浏览器中打开和使用 OpenCAD。命令名称、快捷键和鼠标操作已与桌面版 2D CAD 软件匹配。请先使用示例图纸探索各项功能。

检查DWG·DXF文件打开和显示问题 · 距离·面积测量和 PDF 输出方式

您可以打开哪些 CAD 文件？

支持 DWG R13~R2018 和 DXF R12~R2018（ASCII/二进制）格式的 2D 绘图。您可以检查模型/布局、图层、块、尺寸、剖面线和文本。即使在支持的范围内，某些对象或字体也可能与原始对象或字体不同。

我可以免费编辑和保存图形吗？

查看绘图、测量距离、角度和面积、创建新绘图、绘制和修改绘图、编辑尺寸、图块和图层以及保存为 DWG 和 DXF 格式均免费。同时支持 PDF、PNG 和 SVG 输出。源代码以 MIT 许可证发布。

是否需要将绘图上传到服务器？

所选绘图文件不会上传到服务器。读取文件、显示绘图和保存操作均由当前使用的浏览器处理。无需下载安装文件或创建帐户。
