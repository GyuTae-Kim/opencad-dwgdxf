OpenCAD free DWG·DXF CAD

It is a free 2D web CAD that allows you to open or create new DWG/DXF drawings, draw, edit, and save them. It can be used directly in the browser without installation or membership registration, and drawing files are processed on this computer without being sent to the server.

Supported Formats and Features

  • Open DWG R13~R2018, DXF R12~R2018 (ASCII/binary), create new drawing
  • Drawing lines, polylines, circles, and arcs, modifications such as moving, copying, cutting, and filleting, and grip editing
  • Edit dimensions, leaders, text, hatches, tables, blocks, layers, and layouts
  • Save DWG R2000~R2018, DXF R12~R2018, measure distance/angle/area
  • Output to PDF, PNG, SVG

Once the program is ready, you can start drawing immediately in a ‘New Drawing,’ drag and drop a file, or click ‘Open File.’ You can also explore the features by opening an ‘Example Drawing.’ A browser that supports JavaScript and WebGL2—such as the latest versions of Chrome, Edge, Firefox, or Safari—is required.

Free CAD to check and modify DWG·DXF drawings

When you need to review and edit existing drawings, or create new ones and save them as DWG or DXF files, you can use OpenCAD directly in your browser. Command names, shortcuts, and mouse operations are designed to match those of desktop 2D CAD software. Explore the features using the sample drawings.

Checking DWG·DXF file opening and display problems · Distance/area measurement and PDF output method

Which CAD file formats can be opened?

Supports 2D drawings in DWG R13~R2018 and DXF R12~R2018 (ASCII/binary) formats. You can check model/layout, layers, blocks, dimensions, hatches, and text. Even within the supported range, some objects or fonts may appear different from the original.

Can I edit and save drawings for free?

In addition to viewing drawings and measuring distances, angles, and areas, it is also free to create new drawings, draw and modify them, edit dimensions, blocks, and layers, and save DWG and DXF. PDF, PNG, and SVG output are also supported. The source code is released under the MIT license.

Do I need to upload the drawing to the server?

The selected drawing file will not be uploaded to the server. Reading files, displaying and saving drawings is handled by the browser you are using. There is no need to download installation files or create an account.
